A Linux-based server maintenance automation script designed for WSL and Debian systems.  
It automates package updates, disk cleanup, log rotation, system health checks, backup creation, and supports a safe dry-run mode for testing.

This project is ideal for DevOps learning, automation practice, and system administration workflows.
